# Express + Prisma Project

## Tech Stack
-Node.js
-Express.js
-Prisma ORM
-MySQL

## Project Structure
* routes/ - routes
* controllers/ - route handlers
* prisma/schema.prisma - schema for database(if you change something in this file, you have to write command - 'npx prisma generate' for project to work)


## Setup Instructions command

-git clone repo_link
-cd project-name(eg: express-prisma-project)

install dependencies:
-npm install

-npx prisma generate
-npm start
